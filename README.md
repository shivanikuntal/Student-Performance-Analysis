# Student Performance Analysis

## Project Overview

This project analyzes students' academic performance using Python and Pandas to calculate subject-wise averages and identify the top-performing students.

## Objective

The objective of this project is to analyze student performance across Math, Reading, and Writing scores and present the results through simple data visualizations.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed

- Loaded and explored the student performance dataset
- Checked dataset structure and data types
- Validated the data for missing values
- Checked for negative marks
- Calculated average marks for each subject
- Identified the top 5 performing students
- Calculated total and average marks
- Created bar charts for subject-wise performance
- Created a bar chart for the top 5 students
- Created histograms to visualize score distributions

## Visualizations

- Average Marks by Subject
- Top 5 Performing Students
- Math Score Distribution
- Reading Score Distribution
- Writing Score Distribution

## Dataset

The dataset used in this project is the Students Performance in Exams dataset available on Kaggle.

**Source:** [Kaggle - Students Performance in Exams](https://www.kaggle.com/datasets/spscientist/students-performance-in-exams)
